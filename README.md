# Zaidi Consulting Group

Professional three-page website for Zaidi Consulting Group.

## Pages

- **Home** (`index.html`) — brand introduction and service overview
- **Our Services** (`services.html`) — Revenue Cycle Management, Performance Marketing, Remote Staffing Solutions
- **Contact Us** (`contact.html`) — contact details and inquiry form

## Run locally

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Publish on GitHub Pages (permanent URL)

1. Merge this site to the `main` branch.
2. In the GitHub repo go to **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to **GitHub Actions**.
4. After the deploy workflow runs, the site will be live at:

**https://zcgllc.github.io/ZCG/**

## Update contact details

Edit the email/phone placeholders in `contact.html` to your real business contact information.
